# Sayan Biswas

> Frontend developer & designer. I build things that feel as good as they look.

A one-page portfolio that scrolls like a story — six moments, one page, no
clutter. Built to be fast, responsive, and a little bit fun.

## Built with

**React** · **Next.js** · **TypeScript** · **Tailwind CSS** · **Framer Motion**

## Run it locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

The contact links and some photos are placeholders waiting for the real
